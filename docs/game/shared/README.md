# Shared

Общие листовые модули игры без зависимостей от других зон.
- `card-metadata.js` — ряды, типы, редкость и нейтральная фракция.
- `card-keywords.js` — словарь ключевых слов.
- `effect-schema.js` — схема DSL эффектов.
- `card-filters.js` — чистые фильтры определений карт.
- `score.js` — `rowScore`, `totalScore` и единый `shuffle`.
- `storage-keys.js` — ключи и префикс localStorage.
Разрешены зависимости только внутри `shared/`.
Не импортировать состояние матча, каталог карт, рантайм эффектов, бота или мета-экономику.
