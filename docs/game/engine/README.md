# Engine

Состояние матча, поле, действия и переходы раундов.
- `match.js` — публичный фасад `createMatch`, `applyAction`, правил раундов.
- `match-setup.js` — создание матча, пресеты и перенос монет.
- `match-rounds.js`, `match-actions.js` — ходы, муллиган, пас и действия.
- `board.js` — фасад размещения, силы и статусов.
- `events.js` — чтение способностей и очередь событий.
Разрешены `shared/`, `effects/` и внутренние импорты.
Только `match-setup.js` может импортировать `cards/` ради пресетов и стратагемы.
