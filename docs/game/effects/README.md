# Effects

Рантайм DSL эффектов: выбор целей, операции и работа с стопками.
- `effects.js` — запуск эффектов, приказы, плата и способности лидеров.
- `effect-operations.js` — реестр операций DSL.
- `effect-queries.js` — цели, условия, значения и допустимые предложения.
- `effect-piles.js` — операции с рукой, колодой, сбросом и созданием карт.
Разрешены зависимости от `shared/`, `engine/` и внутри `effects/`.
Исключение: `effect-queries.js` читает `CARD_DEFINITIONS` для рантайма `create-play`.
Каталожный предпросмотр связанных карт находится в `cards/related-cards.js`.
