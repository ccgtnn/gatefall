# Головоломки бота

В меню матча включи «Показывать мысли бота» и нажми «Скопировать позицию». Сохрани JSON в этой папке и добавь к полям `level` и `state` название `name`, условие `description` и проверку `expect`. Копируй позицию на ходу бота или во время его выбора цели.

В `expect` можно указать `type`, `cardId`, `row`, `notCardId`, `notType` или `target` с ID цели. Например, `{"type":"play","row":"surface"}` требует розыгрыш на Поверхность. Опциональное поле `rolloutSamples` задаёт число проб симуляции. Значение 0 оставляет поиск без этих проб.

Запуск из корня репозитория — `node --test tests/bot/puzzles.test.js`.

## Отчёт тестирования

Включи «Тестирование» в быстром матче. Оценивай действия бота через 💬 у поля или в журнале. Кнопка «Скачать отчёт» есть в меню матча и на экране итога. Панель быстрого матча даёт скачать сохранённый отчёт предыдущего или прерванного теста.

JSON версии 1 содержит `summary`, `meta` и `timeline`. Сводка хранит количество действий бота, количество оценок, средний балл и номера ходов с оценкой до 4 включительно. В метаданных указаны время начала, версия Pages при наличии, уровень бота, исходные колоды и лидеры, первый игрок и итог со счётом. У каждого действия есть сквозной `index`, сторона, `action`, описание и компактные события журнала. У действий бота есть отдельный номер `botMove`, мысли `trace` и снимок перед действием `position: { level, state }`. Оценка `rating: { index, stars, comment, at }` хранится в той же записи и использует её снимок и мысли. При превышении 3 МБ выгрузка опускает снимки неоценённых действий. При переполнении localStorage сохранённая копия может опустить все снимки. Причина указана в `positionOmitted`, число пропусков — в сводке.

`node tools/report-to-puzzle.mjs <report.json>` показывает оценённые ходы от худшей оценки к лучшей. Добавь номер `botMove`, чтобы вывести JSON головоломки со снимком. Заполни `expect` вручную перед добавлением головоломки в тесты.
