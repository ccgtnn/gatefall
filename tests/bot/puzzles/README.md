# Головоломки бота

В меню матча включи «Показывать мысли бота» и нажми «Скопировать позицию». Сохрани JSON в этой папке и добавь к полям `level` и `state` название `name`, условие `description` и проверку `expect`. Копируй позицию на ходу бота или во время его выбора цели.

В `expect` можно указать `type`, `cardId`, `row`, `notCardId`, `notType` или `target` с ID цели. Например, `{"type":"play","row":"surface"}` требует розыгрыш на Поверхность. Опциональное поле `rolloutSamples` задаёт число проб симуляции. Значение 0 оставляет поиск без этих проб.

Запуск из корня репозитория — `node --test tests/bot/puzzles.test.js`.
